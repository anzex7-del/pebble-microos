A LITTLE CONNECTION

Hello, real-world Pebble.

For USB, connect the board with a data cable and select port A in desktop Chrome or Edge. For Bluetooth, open Apps → Connect → Bluetooth → Enable 3 min on your device. Connect here to send your design or set the clock.

Chrome or Edge on a Bluetooth-equipped computer or Android device. Safari and iPhone browsers are not supported by this web bridge. Your pet accepts settings from nearby clients during its three-minute window; turn it off when finished.

Ready when your Pebble is. Enable Bluetooth on the device first.

USB sends the pet design. Bluetooth also supports clock sync and pats. Radio behavior in 0.3 still needs testing on your board.

FROM PIXELS TO YOUR POCKET

Put your pet
on your device.

This preview targets the Waveshare T5-E1-Touch-AMOLED-1.75. ESP32 Pip-KeyPet firmware uses a different processor.

Download firmware

  1. Get preview 0.3

    Download the latest successful T5 preview from GitHub Releases. You only need a custom build if you want to change its compiled defaults.

  2. Optional: build custom defaults

    In your fork of the repository, open Actions → Build T5 preview firmware → Run workflow. Paste the profile JSON, or leave it empty for Milo.

    Show profile JSON
  3. Install with the T5 tool
    Install the QIO image using the T5 tool. Then use the Bluetooth controls above to send your pet without reflashing. The 0.2 baseline booted on hardware; new 0.3 features still need a device test.
