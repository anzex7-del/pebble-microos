FROM PIXELS TO YOUR POCKET

Put your pet
on your device.

This preview targets the Waveshare T5-E1-Touch-AMOLED-1.75. ESP32 Pip-KeyPet firmware uses a different processor.

Firmware builds

  1. Save your design

    Download the profile above. It contains your pet’s name, color, eye style and focus length.

  2. Build your preview

    In your fork of the repository, open Actions → Build T5 preview firmware → Run workflow. Paste the profile JSON, or leave it empty for Milo.

    Show profile JSON
  3. Install with the T5 tool
    Download a successful build’s artifact and follow the installation guide. Physical-device validation is still required. Keep your factory recovery image.
    Read the installation guide
